# Attestation conformance vectors

`attestation-vectors.json` is generated by
`scripts/generate_attestation_vectors.py`. It contains TEST ONLY keys and
positive/negative cases consumed unchanged by Python and the clean-room Go
verifier. A conforming verifier must return the recorded error code, not merely
accept/reject.

Categories cover ASCII, Unicode preservation, reordered input canonicalization,
safe integer boundaries, two-key rotation, payload/signature tampering,
algorithm/profile/type/key confusion, unknown critical headers/claims,
freshness, plan/launch/artifact/process-epoch binding, replay, malformed JSON,
duplicate keys, non-finite/float values, and noncanonical payload bytes.

The Go implementation is intentionally self-contained from extension-manager
and Python code. Both implementations share only the JSON vectors and published
profile semantics.
